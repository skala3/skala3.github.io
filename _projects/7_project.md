<p align="justify">An interactive game that combines the courtroom gameplay of Ace Attorney with LLM technology. Players cross-examine AI-generated witnesses to uncover contradictions in their testimonies. The game features dynamic witness statements with embedded contradictions, natural language questioning, and evidence presentation mechanics.</p>

<p align="justify">Built using Large Language Models including Phi-2, Llama-3.2-3B, Llama-3.1-8B, and Llama-3.1-70B. The game includes four case scenarios (murder, theft, accident, arson) and runs fully locally with GPU support - no API keys required. Features a health-based gameplay system where players must carefully manage their 5-health limit while finding contradictions.</p>
