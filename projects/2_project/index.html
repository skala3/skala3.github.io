Ace Attorney Cross-Examination

LLM-powered courtroom game where you question AI-generated witnesses, present evidence, and expose contradictions—fully offline.

LLM Gameplay 2024 100% Local

Project Overview

A Phoenix Wright–inspired gameplay loop powered by local LLMs. Witnesses deliver dynamic testimonies with embedded contradictions; you question them in natural language and present evidence to drain their credibility before your 5-health limit runs out.

Runs entirely on your hardware: small (Phi-2, Llama 3.2 3B), medium (Llama 3.1 8B), or large (Llama 3.1 70B) models. Includes four scripted cases (murder, theft, accident, arson), evaluation harnesses, and GPU-ready configs.

Technology Stack

LLM & Game Loop
  • Local LLM inference (no API keys)
  • Dynamic testimony generation
  • Natural-language questioning & evidence
  • Health-based gameplay loop
Tooling
  • PyTorch / transformers for model loading
  • Prompt-driven case scripts (4 scenarios)
  • Test harnesses and Docker helpers
  • GPU-ready configs; runs offline
