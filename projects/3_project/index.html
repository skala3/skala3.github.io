Project Overview

Production-ready “People You May Know” pipeline built around graph-based candidate generation, feature engineering, ranking, and a FastAPI serving layer. Designed for medium scale (100K–1M users) with cached responses targeting sub-100ms latencies.

The system includes synthetic and SNAP dataset loaders, evaluation scripts (Precision@K, Recall@K, NDCG, MRR), ensemble ranking options, and swaggered endpoints for interactive testing. Benchmarked layers cover candidate generation, feature extraction, and ranking with cache-aware performance.
